This repo demonstrates how a simple WhatsApp chat can be used in AI for a user to get the gist of the chat, as well as ask questions on what the different users are talking about in this chat log. The chat logs were downloaded from WhatsApp into a zip file. When unzipped, the contents are in a `chat.log` text file. This file is used in this demo, where **Ollama** is set to serve in the background. To experience this demo: * Installed Ollama on local MacOS * Installed `gemma3:4b` * Ran `ollama serve` on the command line in terminal so that it listens to queries from this browser and answers questions. 
A sample chat log from WhatsApp is enclosed here.

This chat is embedded into the **qwen3:latest** model, and the user can query any questions based on this chat. The model responds with analysis based on these logs.

A snapshot of the output from the model is indicated at the bottom of this page.

Messages and calls are end-to-end encrypted. No one outside of this chat, not even WhatsApp, can read or listen to them.
